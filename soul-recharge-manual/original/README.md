# Soul Gem Auto Recharge

## v1.1.0

- Rare Curios の Flawed Varla Stone と Saints & Seducers の Soul Tomato を、自動充填の燃料として使えるようにした。Flawed Varla Stone は繰り返し使え、所持品から消えず中身の魂だけが空になる。Soul Tomato は「空/充填済み」の対で、充填済みのほうを通常の魂石と同じように消費する。
- 追加する魂石は MCM ではなく設定ファイルで指定する。新しい `[ExtraGems]` セクションに、1個につき `ExtraForm=<プラグイン名>:<ローカル FormID>` の行を1行書く。出荷時の設定ファイルには 2 行がコメントアウトされた状態で入っています。行頭の ; を外すと有効になります。石の容量・中身の魂・対になる充填済みフォームはプラグインのレコードから読み取るため、ここに書くのは識別子だけ。
- 壊れた行があってもその行だけが無効になり、機能全体は止まらない。設定した行ごとに状態をログへ記録する。例: `RESOLVED`、`PLUGIN_ABSENT`(プラグインがロード順に無い)、`FORM_NOT_FOUND`(プラグインはあるがフォームが無い)、`MALFORMED`(行の書式が誤っている)。
- ESP とセーブレコードへの変更はなく、新しいセーブデータも増えない。「魂石を使用」は追加した魂石にも適用され。`[ExtraGems]` の 2 行が出荷時のままコメントアウトされた状態の場合、セクションが無い場合、または空の場合、v1.1.0 の動作は v1.0.0 と完全に同じ。

## v1.0.0

- 安定版 v1.0.0 として初公開した。近接武器・弓/クロスボウの自動充填に対応し、左手武器・杖の自動充填はオプション(既定OFF、MCMでON)。ESP とセーブレコードへの変更はない。
- 装備時評価と充填音は、今後のアップデートで対応する。
- 設定ファイルのコメントを、利用者向けの平易な説明文に書き直した。設定キーと既定値はすべて変更していない。
- 今後のアップデートでも設定・セーブとの互換性を保つ。更新はファイルの置き換えだけで済む。

## v0.4.0

- 杖(`Staves`)の自動充填を追加した。既定はOFFで、MCMでONにできる。
- 杖は詠唱が終わった後に評価するため、進行中の詠唱を中断しない。
- 瞬間発動・連続放射・召喚の3種類の杖に対応する。
- 外部のStaff Recharge perk(Vokrii/Ordinator)と共存する。perkによる回復分は当方の充填量に混ぜず、両方を併用すると途中で止まることがあった不具合を修正した。
- 常時効果の杖は対象外で、評価しない。
- 既存の設定・セーブへの変更はなく、v0.3.0の設定・セーブと双方向に互換性を保つ。

## v0.3.0

- 「左手の武器も充填」設定(`DualWield`)を追加した。既定はOFF。ONにすると、まず右手の武器を評価し、右手が満充填(または対象外と判定)になった後、同じ命中で左手の武器も独立に評価する。
- 左右の武器個体を別々に識別する。両手が同じ武器を装備していても混同せず、右手の充填に使った魂石・星を左手で再利用することはない。
- 充填処理に時間がかかりすぎる場合の最終チェックを追加した。基準を超えた場合は魂石を消費する前に処理を停止する。
- 診断ページに、最後に評価した対象の手と、左右それぞれの最後の充填量を表示するようになった。
- 新規セーブレコードの追加はなく、追加は`DualWield`設定キーのみ。`DualWield`がOFFなら、動作とセーブ互換性はv0.2.2と同一。

## v0.2.2

- MCMを開くと既定で「設定」ページが表示されるようになった(以前は「診断」ページが先に表示されていた)。「診断」はページの一覧から選ぶと表示できる。
- 診断ページの各項目は、これまでの内部コードの表示に代えて、平易な説明文の末尾に(コード)を添えた表示になった。例:「充填しました (VERIFIED)」。
- 診断の項目名を3つ、分かりやすく変更した。「最後の自動充填の結果」「いま処理中の充填」「最後に停止した理由」。
- DLL、ESP、魂石の消費処理の変更はない。既存のセーブと設定ファイルはそのまま使える。

## v0.2.1

- 弓・クロスボウの発射(リリース)検出がセッション中に失われた場合、以後は自動で対応する。適格な命中が検出済みの発射に結び付かない状態が2回連続すると、命中時のみで判定するv0.1相当の動作に切り替わる。切り替わりを判定したその命中も、通常どおり再充填の対象になる。発射検出が再び確認できた時点で、発射後判定の動作に戻る。
- MCMの診断ページのnative版表示を修正した。これまで0.1.0と表示していたが、0.2.1と表示するようになった。
- 診断用の設定として、INIの`[Ranged]`に`UnlinkedHitLimit`(既定2)と`UnlinkedHitWindowMs`(既定3000)を追加した。上記の切り替えに使う連続回数と時間の設定。
- さらに診断専用の設定として`DiagDropReleaseAfter`と`DiagDropReleaseCount`(既定0と2)を追加した。検証者が発射検出を一時的に一定数だけ意図的に隠し、切り替え・復帰の動作を確認するための設定であり、出荷時の既定(`DiagDropReleaseAfter=0`)では無効で通常プレイに影響しない。
- 消費処理、ESP、`Native.pex`、MCM PEXの変更はない。MCMの設定ページも変更しない。

## v0.2.0

- 弓とクロスボウの充填を有効にすると、v0.2.0では付呪された弓とクロスボウの発射後にも充填を判定する。外れた矢も対象になる。残量が設定したしきい値以下で、魂の入った魂石または星を所持している必要がある。
- 「弓とクロスボウを充填」(RangedWeapons)をOFFにすると、発射後と命中時の両方で弓とクロスボウの自動充填を停止する。同じ設定をOFFにしたv0.1相当となり、右手系近接武器の動作は変わらない。OFFは弓の命中時のみの充填を選ぶ設定ではない。
- 使用中のアニメーション構成で発射を検出できない場合、診断ページに検出を利用できない状態、または命中時のみの対応を表示する。この場合は適格な命中時にv0.1と同じ動作となり、外れた矢では充填しない。検出を確認する前は未確認、確認できると利用可能と表示する。
- MCMの設定は引き続き9項目となる。RangedWeaponsは既存の設定で、既定値はONのままとし、更新時には保存済みの値を引き継ぐ。
- 魂石の選択、星の再利用、保護設定、回復量、付呪スキル経験値、Soul Gems Used統計、手動キー、設定の保存方法は変更しない。無料の充填は行わない。
- 二刀流、左手武器、杖、装備時の判定、従者、NPCは引き続き対象外となる。以下のv0.1の説明は旧版の記録とし、v0.2.0の変更は本節に記載する。

魂石を使った武器の再充填を自動化します。対応する武器の残量が設定したしきい値以下になったあと、プレイヤーが次に命中させると、所持品から魂石または星を使って武器を最大まで再充填します。

無料回復はありません。消費する魂石、回復量、付呪スキル経験値、Soul Gems Used 統計は、バニラの手動再充填経路に合わせます。星は再利用し、既定では星を最優先します。星を使い切ったあとは、魂の大きさが小さいものから通常魂石を選びます。黒魂石は既定で温存します。

## v0.1 の対応範囲

- プレイヤーが装備している右手系の近接武器 1 本。両手持ち近接武器を含みます。
- プレイヤーが装備している弓またはクロスボウ。v0.1 では命中時に評価します。外れた矢では評価しません。
- 二刀流、左手武器、杖、装備した時だけの評価は未対応です。今後の版で機能ごとに追加します。
- 従者と NPC は対象外です。従者のリチャージは、NFF を使っている場合も NFF に任せます。

自動充填は既定で ON（`Enabled=1`）です。MCM でいつでも OFF にできます。アズラの星は未検証で、黒き星は検証済みです。

## MCM 設定

設定と診断の 2 ページで構成します(v0.1 は 9 項目、v0.3.0 で `DualWield` を追加し 10 項目、v0.4.0 で `Staves` を追加し 11 項目)。

| 設定 | 既定値 | 説明 |
|---|---|---|
| 自動充填を有効化 | ON | 自動処理全体を停止できます。 |
| 充填のしきい値 | 20% | 残量がこの値以下になったあと、次の適格な命中で評価します。 |
| アズラの星と黒き星を優先 | First | 充填された星を通常魂石より先に使います。 |
| アズラの星を使用 | ON | アズラの星を候補にします。 |
| 黒き星を使用 | ON | 黒き星を候補にします。中身の魂の色は判定しません。 |
| 魂石を使用 | ON | 通常魂石を候補にします。 |
| 黒魂石を温存 | ON | 黒魂を保持できる通常魂石を候補から外します。 |
| 極大魂石を温存 | OFF | 極大の容器である通常魂石を候補から外します。星には適用されません。 |
| 弓とクロスボウを充填 | ON | 弓/クロスボウの命中時・発射後評価(外れた矢を含む)を有効にします。 |
| 左手の武器も充填 | OFF | ONにすると、右手の充填後に左手の武器も独立に評価します。 |
| 杖も充填 | OFF | ONにすると、詠唱が終わった後の杖を評価します。瞬間発動・連続放射・召喚の杖に対応し、常時効果の杖は対象外です。 |

魂石の中身は個体ごとに評価します。空の魂石は使わず、星を使った場合は個数と所持状態を保ったまま中身だけが空になります。

設定ファイル(INI)には、追加の魂石を並べる `[ExtraGems]` セクションもあります。書式は1行につき `ExtraForm=<プラグイン名>:<ローカル FormID>` で、たとえば `ExtraForm=ccbgssse037-curios.esl:0x000801` です。出荷時の設定ファイルには 2 行がコメントアウトされた状態で入っています。行頭の ; を外すと有効になります。石の容量・中身の魂・対になる充填済みフォームはプラグインのレコードから読み取るため、ここに書くのは識別子だけです。プラグインが無い(`PLUGIN_ABSENT`)、フォームが見つからない(`FORM_NOT_FOUND`)、行の書式が誤っている(`MALFORMED`)行はその行だけが無効になり、状態は行ごとにログへ記録されます。ほかの行はそのまま動作します。

## 導入

1. 念のため手動セーブを作成します。
2. MOD マネージャーで配布パッケージ全体を導入し、`AGH_SoulRecharge.esp` と対応 DLL を有効にします。
3. ゲームを起動し、MCM に「魂石オートリチャージ」が表示されることを確認します。
4. 最初は診断ページで DLL の状態と設定を確認します。

新規ゲームは必要ありません。設定はセーブではなく profile の `Data/SKSE/Plugins/AGH_SoulRecharge.user.json` に保存されます。配布パッケージにこの user ファイルは含まれません。

## 手動キー

- F11 は手動で 1 回だけ充填します。自動処理と同じ魂石の選択規則と保護設定に従い、満充填なら何もしません。
- F10 は診断スナップショットをログにだけ出力します。どちらのキーも INI で変更できます。
- 設定ファイルが破損している場合は自動停止し、診断に `USER_CORRUPT` を表示します。

## 更新

DLL、ESP、PEX、翻訳ファイルを含む同じ版のパッケージ全体を置き換えてください。異なる版の DLL/ESP/PEX を混ぜないでください。既存の設定ファイルは保持され、共有キーは引き継がれます。新機能のトグルは追加時に OFF から始まります。

## 停止・削除・rollback

通常の停止は MCM で「自動充填を有効化」を OFF にし、診断で pending/実行中の処理が idle になったことを確認してからゲームを終了します。既に消費した魂石、武器 charge、経験値、統計は返金・巻き戻ししません。

機能を止めたままセーブを継続する場合は、DLL を含まない停止用パッケージ（同じ FormID の ESP/PEX stub）へ置き換えます。stub は DLL 不在時に native を呼ばず、設定を保持するだけです。停止用パッケージの zip には stub の ESP/PEX とこの説明を含め、通常版の DLL と混在させないでください。

rollback は、MCM で Enabled を OFF → 通常セーブ → ゲーム終了 → MOD を無効化して通常版を完全に除去し、直前の合格版の zip 全体、または STOP zip の中身全体で完全に置き換える（マージはせず、DLL を含む旧ファイルを残さない）→ `AGH_SoulRecharge.user.json` を保持 → 同じセーブをロード、の順です。版、設定、停止理由を確認してから必要なら ON に戻します。旧版にないキーは無視されます。

進行中セーブから ESP/PEX まで完全に削除する安全は保証しません。完全削除が必要な場合は、導入前に作ったセーブ、または新規ゲームを使ってください。save cleaner、base の修復、セーブの直接編集は使用しません。

## 確認済みの経済挙動

実測した検証構成では、Soul Squeezer 有効時の回復量は魂レベル 1/3/5 でそれぞれ 500/1250/3250（最大 charge を超える分は切り捨て）でした。基礎 XP 入力の実測値はそれぞれ 103.5/258.75/672.75 です。極大魂石で残り 175 charge を埋めた場合も魂 1 個を消費し、余剰 3075 は保存しません。星は個数を減らさず、中身だけを空にします。

## 既知の制約と共存

- 弓/クロスボウは命中時と発射後(外れ矢を含む)の両方で評価します(v0.2.0以降)。一部の遅延・特殊な弾道ケースは対象外です。
- 二刀流(左手の武器)はv0.3.0、杖はv0.4.0で対応しました。既定はいずれもOFFで、MCMの「左手の武器も充填」「杖も充填」でONにできます。杖は詠唱の終了後に評価し、瞬間発動・連続放射・召喚の3種に対応します。常時効果の杖、装備時評価、従者/NPC、完全な全武器対応は未対応です。
- 外部のStaff Recharge perk(Vokrii/Ordinator)と併用できます。perkによる回復分は当方の充填量に混ぜません。
- 「負荷ほぼゼロ」は設計目標であり、環境を問わない実測結果ではありません。対応環境での raw frametime 計測は検証後に追記します。
- NFF の従者リチャージは NFF に任せます。当方の Default 環境では NFF との併用を確認しています。NFF の設定、レコード、NPC 所持品は変更しません。
- SmartHarvest とは共存できます。
- Recharge Framework との同時導入は非対応です。

## 更新方針

1 版 1 機能を基本とし、各追加機能は個別トグルで切り分けられるようにします。既定値は保守的にし、変更した機能だけを次版の対象にします。対応範囲や性能の保証は、実測した runtime と構成に限定します。
